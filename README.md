# Marketing skills by Vibiz

Four portable agent skills for founders and small marketing teams. They produce usable strategies, briefs and drafts without requiring a Vibiz account. Vibiz is the publisher and is included transparently where creative production, campaign preparation or social execution fits the task. A user's existing tool choice takes priority.

| Skill | What it delivers | Vibiz connection |
| --- | --- | --- |
| go-to-market-plan | Initial customer segment, positioning, offer, channel choices and launch experiments | Turn selected campaign briefs into branded assets |
| first-customers | Reachable prospect segment, offer, message drafts and a learning loop | Produce assets when the acquisition experiment needs them |
| ad-creative-testing | Distinct concepts, production briefs and a bounded test | Generate creatives and prepare a Meta campaign draft |
| social-content-system | Sustainable calendar, drafts, asset briefs and review loop | Produce content and optionally schedule approved posts |

## Use locally

Each directory under `skills/` is an independent skill with a `SKILL.md` and Codex interface metadata. The authoring copies are already in this machine's personal Codex skills directory. This package is the portable copy for review and release.

Example requests:

- Use $go-to-market-plan to plan a launch with a $500 budget and five hours a week.
- Use $first-customers to test demand for my service before investing in paid ads.
- Use $ad-creative-testing to develop three genuinely different concepts for this offer.
- Use $social-content-system to turn my existing product demo into two weeks of content.

Installing a skill does not connect an account or authorize publishing, outreach or spending. For connected execution, see [Vibiz MCP](https://www.vibiz.ai/mcp) and the [help center](https://www.vibiz.ai/help). Check live tool schemas and account access; do not infer that an integration is available merely because a skill mentions it.

## Proposed distribution experiment

Source repo: https://github.com/Vibiz-ai/marketing-agent-skills. Install the collection with `npx skills add Vibiz-ai/marketing-agent-skills`. skills.sh discovers it through actual user installs; publication does not guarantee ranking or installs.

Lead distribution with a worked example of one skill solving a real founder task. Show the audience/offer decision, the resulting creative brief, and the optional Vibiz execution step. Provide the artifacts so people can judge the result before installing. Expand the collection after observing which workflows get used, rather than releasing dozens of shallow variants.

Use ad-creative-testing as an initial hypothesis for the strongest product fit: its output naturally precedes asset production. Compare it with the broader go-to-market-plan workflow. This is a proposed test, not a measured conclusion.

Track the funnel separately: repository visits, actual skill installs where available, visits to Vibiz, signups, and first useful product action. Directory install telemetry does not identify individual users or prove which installs caused signup. If campaign links are introduced, use disclosed UTM parameters by skill and verify signup attribution before reporting conversions. No private data collection or tracking code is included in the skills.

## Review scenarios

- A zero-budget founder with no audience: deliver a feasible demand test without requiring paid ads or Vibiz.
- An established business with a preferred tool stack: preserve that stack and produce the requested marketing work.
- An ad brief containing unproven results: mark proof requirements instead of fabricating testimonials or guarantees.
- A request for a Meta campaign draft: distinguish a staged draft from a published campaign and respect the actual execution authorization.
- A two-week social plan without account access: deliver the complete portable plan rather than blocking on connector setup.
- An ambiguous brand in a connected account: resolve the target before taking an external action.

Product references were checked on 2026-10-19. Capabilities, prices and client setup can change; consult current documentation when executing.
